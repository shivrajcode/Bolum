BOLUM 1.0.1

Speak here.
Write anywhere.

A small desktop dictation app for macOS and Windows. Speak with a shortcut, then put your words into the app you’re using.

Start / stopCtrl+⌥ / Alt+Space

Speech recognition runs on your computer with NVIDIA Canary or Parakeet. Download a model once, then dictate offline.

SETUP

Install Bolum

macOS · Apple Silicon

For M1 and newer Macs, macOS 13.4 or later.

  1. Download the macOS .pkg installer.
  2. Open the package and follow the installer. It places Bolum.app in Applications.
  3. Open Bolum. If macOS blocks the unsigned publisher, review it under System Settings → Privacy & Security → Open Anyway.
  4. Enable Microphone and Accessibility for Bolum.

Windows · x64

A per-user installer for 64-bit Windows desktops.

  1. Download the Windows setup.exe installer.
  2. Run setup and choose an installation folder. No administrator account is required.
  3. Open Bolum from the Start menu. You can uninstall it from Windows Settings.
  4. Allow microphone access for desktop apps in Windows Settings.

These builds are not publisher-signed or Apple-notarized. Download only from the official GitHub releases. Each release includes SHA-256 checksums. The buttons above track the latest passing main build; numbered releases stay available. Model weights are downloaded separately.

Your first dictation

  1. Choose your voice model. Open Models, download Canary or Parakeet, and select Use model.
  2. Put your cursor where you want the text. Open a text editor or another app with an editable field.
  3. Press your shortcut and speak. Control–Option–Space on Mac, or Control–Alt–Space on Windows.
  4. Press it again to finish. Bolum transcribes and inserts your words. Escape cancels an active recording.

Record a sample is a microphone test. Its result stays inside Bolum and is never pasted into another app.

Canary uses less disk space. Parakeet is faster in our English fixture tests. Actual latency and accuracy depend on your speech and hardware. Choose the spoken language in General when using Canary.

Loading starts while you record. The model stays in memory for 60 seconds after use by default. Change Advanced → Unload model if you dictate frequently. Longer recordings take longer to process.

Settings & history

General
Set your shortcut, microphone and shortcut behavior. Toggle starts and stops with a press; Hold records while held; Auto supports both.
History
Copy or remove recent transcripts. History stays in memory, with 20 entries by default. Quitting clears it.
Advanced
Choose Clipboard paste, Direct typing, or Show in Bolum only. Configure the overlay, idle timeout, quiet-edge trimming, filler removal and exact word corrections.
About
Choose a purple light, dark or system theme, open the app’s data folder, and access macOS permission settings.

Auto submit sends Enter after insertion. Keep it off when you want to review your words before sending a message. Clipboard paste replaces your clipboard text.

When something needs attention

The transcript appears, but it isn’t pasted

On macOS, open Privacy & Security → Accessibility and enable the installed Bolum.app. The Enable automatic pasting button opens this setup. If an older build remains in the list, remove it and add the current app again.

Check Advanced → Paste method is set to Clipboard paste or Direct typing. Use the shortcut from the destination field, not the sample button. If you change to another app during dictation, Bolum copies the result for you to paste manually.

Until macOS grants access, Bolum cannot send Command-V. The result remains in History and is copied to the clipboard when insertion fails.

The microphone is silent or unavailable

Allow microphone access, select the correct input in General, and use Refresh devices after connecting a headset. Watch the input meter while recording. A sample recording can check the microphone and model without typing anywhere.

Transcription takes too long

Try Parakeet v3 for faster dictation on supported hardware. Keep the model loaded longer in Advanced if you dictate often. Pause less before stopping, or enable quiet-edge trimming if your recordings contain long quiet ends.

Your voice stays local

Audio is captured only while recording and is not saved to disk. Speech recognition runs locally; no transcription API, cloud cleanup service or account is used. Downloading a model requires the internet, and external links open in your browser.

Settings and model files are stored on your device. Session history is cleared on exit. Paste mode copies the transcript to your system clipboard, where other applications may be able to read it.

Build from source

The desktop app is Rust with egui and ONNX Runtime. There is no Node, Python or webview runtime to ship. Install the Rust toolchain and your platform’s native build tools, then:

git clone https://github.com/shivrajcode/Bolum.git
cd Bolum
cargo run --release

Build the macOS bundle with sh scripts/package-macos.sh. On Windows, install NSIS 3, then run ./scripts/package-windows.ps1 from PowerShell. See the repository README for Linux prerequisites and architecture.

cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --all-targets

With Bolum running, bolum diagnostics reports the selected model, insertion mode, permission status and last inference duration, without returning transcript contents.
